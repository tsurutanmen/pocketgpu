# 先例の調べ（2026-10-07・調べものの助手）

公開の文で「世界初」と言えるかを確かめた。読み取りだけで調べた。公開の直前にもう一度同じ検索をする。

## 結論
- 「世界初」とは言えない。部品ごとには先例がある
- 組み合わせ全体（Windows の ICD・USB の先の iPhone・MoltenVK・改造なしの汎用アプリ・DXVK 経由の D3D11）と同じ物は、この検索では見つからなかった。見つからないことは、無いことの証明にならない
- 近い試作が直近 2 週間に何本も出ている

## 近い先例
| 名前 | いつ | 同じ点 | 違う点 |
|---|---|---|---|
| vulkan-stream（DUOLabs333） | 2023-09〜2025-11 | Vulkan を TCP で流す ICD。受け手は MoltenVK で Apple の GPU | Mac が受け手、Linux が使う側。iPhone も Windows も無い |
| vulkan_remote（water-chika） | 2026-09-24〜 | Windows の ICD が Vulkan を転送。VK_ICD_FILENAMES で読ませる。vkcube と vulkaninfo | 相手は Linux の GPU。Vulkan 1.0 まで。スマホ・MoltenVK・DXVK は無い |
| remotevk（acceleration3） | 2025-11 | Vulkan ICD で遠隔の GPU | Linux 向け・README 無し |
| Juice Labs | 2020〜 | Windows の改造なしのアプリが遠隔の GPU を使う | 受け手は NVIDIA だけ |
| Venus・gfxstream | — | Vulkan を直列化して送る ICD | 仮想マシンの中から同じ機械の GPU へ |
| Backburner（StayLameBro） | 2026-10-01 | iPhone 17 Pro Max を USB-C でつなぎ、GPU に LLM の層を担当させる。「iPhone を 2 枚目の GPU に」と報じられた | Apple Silicon の Mac 専用。llama.cpp の改造版との専用の通信で、Vulkan の GPU としては見せない。Windows 非対応 |
| LLMDroid | 2026-10-02 | Android が Windows の PC を助ける、という説明 | README では雛形で Vulkan は未実装。実機で動いたかは確かでない |
| HeteroMesh | 2026-10-07 | Windows と Mac と iPhone の推論クラスター | 設計中。iPhone の実機推論は未実施 |

## 向きが逆の物（DirectX と iPhone）
- アプリも GPU も iPhone の中：Madeira（2026-03・FEX-Emu と Wine と DXMT）、Playport（2026-10-01）、Generals の iOS 移植
- アプリも GPU も Android の中：Winlator・GameNative・GameHub
- 絵だけ手元へ：Moonlight・Steam Link
- 「DirectX 11 を iPhone の GPU で描いた」だけなら 2026-03 から先例がある。「PC のアプリが」を必ず付ける

## 言い方の案（最後の文は本人が書く）
1. 「2026 年 10 月に調べた範囲では、Windows のアプリが USB でつないだ iPhone の GPU を Vulkan の GPU として使う公開例は見つからなかった。」
2. 事実だけ：Windows 用の Vulkan ドライバが呼び出しを USB 越しに iPhone のアプリへ送り、iPhone の中では MoltenVK を通して Apple の GPU が動く。改造なしの llama.cpp・whisper.cpp・stable-diffusion.cpp が動き、DirectX 11 のアプリも DXVK を通して動いた。
3. 先例との違い：iPhone の中でアプリを動かすのではなく、PC のアプリが iPhone の GPU を借りる。LLM 専用の分割ではなく、Vulkan の呼び出しをそのまま送る。近い先例には Backburner と vulkan_remote がある。
